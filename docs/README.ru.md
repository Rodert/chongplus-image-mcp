# ChongPlus Image MCP

MCP-сервер, который позволяет AI-ассистентам генерировать и редактировать изображения через ChongPlus Image API.

[English](../README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md) | [Español](README.es.md) | [한국어](README.ko.md)

Сервер рассчитан на обычное использование в чате: после установки AI проверяет, сохранен ли API Key, спрашивает его только при необходимости и сохраняет локально. Переменные окружения и ручной запуск Python не нужны.

## Возможности

- Проверка готовности ChongPlus к работе.
- Безопасное сохранение или замена ChongPlus API Key.
- Генерация от одного до четырех изображений по промпту.
- Редактирование локального референсного изображения.
- Информация о доступных размерах и ограничениях.

Сгенерированные изображения сохраняются локально. Инструменты возвращают абсолютные пути, по которым MCP-клиент может открыть или показать изображения.

## Установка

Проще всего попросить AI-клиент с поддержкой MCP установить этот репозиторий. Для ручной настройки используйте `uvx`:

```json
{
  "mcpServers": {
    "chongplus-image": {
      "command": "uvx",
      "args": ["--from", "git+https://github.com/Rodert/chongplus-image-mcp", "chongplus-image-mcp"]
    }
  }
}
```

Для уже склонированного репозитория используйте:

```json
{
  "command": "uv",
  "args": ["run", "--directory", "/absolute/path/to/chongplus-image-mcp", "chongplus-image-mcp"]
}
```

## Первое использование

Попросите AI сгенерировать или отредактировать изображение. Он сначала вызовет `setup_status`; если ключ не сохранен, попросит ChongPlus API Key и вызовет `configure_api_key`.

Получите ключ в [ChongPlus Keys](https://api.chongplus.plus/keys): войдите, создайте ключ и выберите группу генерации изображений. API Key - конфиденциальная информация. Передавайте его только доверенному AI-клиенту и локальному MCP-серверу.

Место хранения ключа:

| Платформа | Путь |
| --- | --- |
| macOS/Linux | `$XDG_CONFIG_HOME/chongplus-image/config.json` или `~/.config/chongplus-image/config.json` |
| Windows | `%APPDATA%\\chongplus-image\\config.json` |

В macOS/Linux каталог имеет права `0700`, а файл - `0600`.

## Инструменты

| Инструмент | Назначение |
| --- | --- |
| `setup_status` | Проверяет, сохранен ли локальный API Key. |
| `configure_api_key` | Безопасно сохраняет API Key пользователя; сервер никогда не возвращает ключ. |
| `generate_image` | Генерирует изображения по промпту. |
| `edit_image` | Редактирует локальное изображение. |
| `list_image_options` | Показывает поддерживаемые размеры и ограничения. |

`edit_image` принимает только путь к локальному изображению, а не URL. Сервер также не возвращает содержимое произвольных локальных файлов.

## Разработка

Требуются Python 3.10 или новее и [uv](https://docs.astral.sh/uv/).

```bash
uv sync
uv run python -m unittest discover -s tests
uv run chongplus-image-mcp
```

Тесты работают без сети и не требуют API Key.

## Ошибки

- `401` или `403`: API Key может быть недействительным, не иметь доступа к модели изображений или не иметь квоты.
- `403` с Cloudflare `1010`: пограничный firewall заблокировал запрос до обработки API. Обратитесь в поддержку ChongPlus и укажите примерное время запроса.
- Ошибки соединения: проверьте сеть и повторите попытку.

Источником истины по API служит [документация ChongPlus Image API](https://api.chongplus.plus/tools/image-studio/docs/).
